This is an Arduino sketch for 128x64 LEDs, using the FastLED library.

It shows a slowly rotating 3-dimensional scene. The scene is a pyrotechnic display.

We need an advanced 3D particle system with gravity, which can be re-used for many types of fireworks. Concentrate on the fidelity of the trails. Perhaps use multiple short line segments with different colours to convey temperature fall off.

1. Fountain: a fountain is a ground level display. Numerous tiny particles spew out of the top, mostly cooling before they hit the ground. Each fountain emits a different colour of sparks.

2. Catherine Wheel: a thin, spoked wheel, with two rockets placed diametrically opposed. The two rockets point in opposite directions always. The thrust from the rockets spins up the wheel. As the speed increases the sparks from the rockets fly off faster.
